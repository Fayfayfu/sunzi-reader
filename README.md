# 兵法研读室 · 孙子十三篇

十三篇原文、叶玉麟译文、字词注释、古注和全书脉络。当前公开版本无需注册；阅读进度和已读标记保存在当前浏览器，暂不提供跨设备同步。

## 本地构建与部署

使用 Node.js 22，执行 `npm ci` 和 `node scripts/build-vercel.mjs`。网页输出在 `dist/client`。Vercel 根据 `vercel.json` 构建，框架选 Other。阅读页使用 hash 路由，句子和段落链接可直接打开。

将 main 分支推送到关联的 GitHub 仓库，Vercel Git 集成会自动部署生产站点。无需自有域名，可以使用 Vercel 分配的地址。

## 暂缓的账户功能

`public/account.js` 中的 `accountsEnabled` 当前为 false：不初始化账户服务、不请求账户 API，旧的 `#account` 地址转到“我的研读”。登录入口已从导航移除。此前的账户实现和原站云端记录没有删除。

保留的 `api/[resource].js` 是原站邮箱服务的受限代理，当前阅读流程不依赖它。以后启用邮箱注册前，需要配置 Supabase Email 和可正常投递的 SMTP，验证实际收信、身份隔离及跨设备进度，再恢复账户入口。不能只打开开关就宣称已支持注册。

## 本地进度

浏览器存储按域名隔离。原站与 Vercel 站点的本地进度不会自动互通。清除浏览器网站数据会清除该浏览器保存的进度。
